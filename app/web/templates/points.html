Дни — по журналу мест: где велосипед стоял в каждый момент, там и его день{% if money_ok %}; деньги — по точке аренды, к которой относится запись журнала: своя аренда, иначе аренда клиента в тот день, иначе ближайшая — как в окупаемости{% endif %}. Пока велосипед в аренде, он числится на точке аренды, поэтому дни и деньги точки считают одни и те же велосипеды. «Итого» — сумма строк и совпадает с тремя числами сводки за тот же период.

План — месячный план точки в день (велосипеды × чек; чек без своего — общий чек плана), умноженный на сутки периода. «Выполнено» — выручка точки к плану, цвет — к ровному темпу на сегодня, как у плана на сводке. «Итого» плана — только по точкам с планом. План задаётся на странице точки.

{% endif %}

«{{ NO_POINT_TITLE }}» — то, что к точке не привязать: велосипед, не поставленный ни на одну точку,{% if money_ok %} платёж клиента, у которого не было аренд,{% endif %} наряд на чужую технику без точки. Без этой строки сумма по точкам не сошлась бы с общей.

Выдачи — аренды, начатые за период; продления — периоды после первого, начисленные за период. Идёт аренд и парк — сейчас, а не за период{% if money_ok %}; долг — тоже сейчас: минус клиента целиком на точке его последней аренды, делить баланс между точками нельзя. Наличные — по кассовым сменам точки{% endif %}. Наряды — закрытые за период, по точке ремонта{% if money_ok %}; сервис — оплаченные клиентские наряды, в выручку аренды они не входят{% endif %}.
