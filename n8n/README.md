# Telegram-бот проверки по чёрному списку (n8n)

Готовый workflow для n8n: пользователь пишет боту слово или несколько слов
(фамилию, имя, телефон — что угодно), бот ищет совпадения по строкам
Google-таблицы и отвечает по каждому найденному человеку — в чёрном списке
он или нет.

Файл для импорта: **[`blacklist-bot.workflow.json`](blacklist-bot.workflow.json)**

## Как это работает

```
Telegram Trigger → Разбор запроса → Это поиск?
                                      ├─ да → Google Sheets (все строки)
                                      │        → Поиск и проверка ЧС → ответ в Telegram
                                      └─ нет (команда /start, пустое, 1 символ)
                                               → подсказка в Telegram
```

- Поиск регистронезависимый, по **всем колонкам** таблицы.
- Несколько слов = логическое «И»: строка подходит, только если в ней
  встречаются все слова (`Иванов Иван` не выдаст всех Ивановых).
- Статус берётся из колонки **`ЧС`**: значения `да`, `yes`, `true`, `1`,
  `+`, `чс`, `в чс`, `blacklist` (регистр не важен) считаются «в чёрном
  списке», всё остальное — «не в ЧС».
- В ответе максимум 10 совпадений (настраивается).

## Формат таблицы

Первая строка — заголовки колонок. Пример:

| ФИО | Телефон | Комментарий | ЧС |
|---|---|---|---|
| Иванов Иван Иванович | 79001234567 | не вернул велосипед | да |
| Петров Пётр Петрович | 79007654321 | | нет |

Обязательных колонок нет: имена и состав колонок любые, но колонка со
статусом по умолчанию должна называться `ЧС`, а колонка с именем — `ФИО`
(обе переименовываются в настройках, см. ниже).

## Установка

1. **Создайте бота**: в Telegram напишите [@BotFather](https://t.me/BotFather)
   → `/newbot` → получите токен.
2. **Импортируйте workflow**: в n8n «Add workflow → Import from File» и
   выберите `blacklist-bot.workflow.json`.
3. **Подключите Telegram**: в узлах «Telegram: входящее сообщение»,
   «Telegram: результат» и «Telegram: подсказка» выберите (или создайте)
   credential с токеном бота — один и тот же во всех трёх узлах.
4. **Подключите Google Sheets**: в узле «Google Sheets: таблица людей»
   выберите credential Google (OAuth2 или Service Account), затем в полях
   Document и Sheet — свою таблицу и лист.
5. **Активируйте workflow** (переключатель Active). Telegram-триггер сам
   зарегистрирует webhook — n8n должен быть доступен по HTTPS
   (облачный n8n подходит как есть).
6. Напишите боту `/start` — придёт подсказка. Затем пришлите фамилию —
   придёт результат проверки.

## Настройка под свою таблицу

Все настройки — в начале кода узла **«Поиск и проверка ЧС»**:

```js
const CONFIG = {
  blacklistColumn: 'ЧС',    // колонка со статусом чёрного списка
  positiveValues: ['да', 'yes', 'true', '1', '+', 'чс', 'в чс', 'blacklist'],
  nameColumn: 'ФИО',        // колонка, которая показывается первой в карточке
  maxResults: 10,           // максимум совпадений в одном ответе
};
```

Минимальная длина запроса (по умолчанию 2 символа, чтобы по одной букве не
вываливать всю базу) настраивается в узле «Разбор запроса».

## Ограничения и заметки

- Бот отвечает **всем**, кто ему напишет. Если в таблице персональные
  данные — ограничьте доступ: в узле «Разбор запроса» проверяйте
  `msg.from.id` по списку разрешённых Telegram ID и при чужом ID ставьте
  `is_search: false`.
- Таблица читается целиком на каждый запрос. Для сотен и тысяч строк это
  нормально; для десятков тысяч лучше перенести данные в базу и заменить
  узел Google Sheets на Postgres/MySQL с `WHERE ... ILIKE` — остальной
  workflow не меняется.
- Вместо Google Sheets подойдёт любой источник, который возвращает строки
  как элементы n8n (Airtable, NocoDB, Baserow): поиск в узле
  «Поиск и проверка ЧС» смотрит на все поля элемента и не привязан к
  Google Sheets.
